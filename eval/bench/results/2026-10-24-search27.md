# Terminal-Bench 2.0 search27 baseline with the native RSI harness (#3135, #3685)

Status: batches 2, 3 and 4 are final (batch 4 is a second model, k=1, filled in at the end).

## Method

- **Benchmark**: Terminal-Bench 2.0, `https://github.com/harbor-framework/terminal-bench-2`
  pinned at `2fd12b88aafdd04a52c298e3940bcb189f9766d6` (Harbor parity 0.24.0, `eval/bench/tb2/dataset.toml`).
- **Tasks**: the 30 `search` split tasks of `eval/bench/tb2/split.json` minus the 3 the `$0` oracle
  run (job `2aa4e94a`) found unsolvable or environment-limited: `caffe-cifar-10` (reference
  solution past the agent deadline), `install-windows-3.11` (QEMU/KVM check), `rstan-to-pystan`
  (reference solution crashes, `pkg_resources` missing). 27 tasks. See "Oracle findings" in
  `eval/bench/README.md`. The held-out split is not used.
- **Agent**: RSI's native harness (`session.harness.*` route only; the post-run route audit marks any
  other model invocation `invalid_route`). Runner: the in-daemon Rust runner (`rsi-eval bench tb2`),
  trials in the pinned task images on one laptop Docker host over ssh. No Python in the run path.
- **Model**: batches 2 and 3 `deepseek/deepseek-v4.1-flash` (per-task cap `$0.40`), batch 4 `z-ai/glm-5.3-flash` (`$0.30`); both via OpenRouter, effort `high`.
- **Metric**: pass rate = mean of per-task pass fractions; CI = 95% task-clustered bootstrap
  (10,000 resamples) for k>1, Wilson for k=1. pass@k is the unbiased estimator. Invalid trials are
  excluded and counted. Produced by `rsi-eval bench report <record.json>`.
- **Run configs** (committed): `eval/bench/tb2/runs/search27-flash.toml` (k=1),
  `eval/bench/tb2/runs/search27-flash-k3.toml` (k=3). Concurrency 3.

## Caveats and known measurement issues

- `suspected solution lookup` is set on 44 of the 81 batch-3 trials. These are scanner false
  positives: the matches are the bench system prompt's own "Do not fetch Terminal-Bench, Harbor ..."
  text echoed in the trace (#3942). Every tool call of batches 2 and 3 was checked: the only
  mention is `constraints-scheduling` writing "Terminal-Bench" as a calendar PRODID string (3 passing
  trials); no command or fetch reaches the benchmark hosts.
- Earlier attempts are not part of the numbers: batch 1 (all 27 trials `invalid_route`, #3935, and a
  broken container shell, #3941, $0.36) and a first batch 3 (55 trials refused by a stale launch
  policy, 26 valid, $0.93) are excluded as invalid runs.
- Single laptop, one seed per attempt; model sampling is not seeded, so reruns differ by the spread above.
