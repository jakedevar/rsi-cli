# The binaries the e2e_tui harness needs on disk before its tests run (#1651,
# #1637). This is the ONLY definition of the e2e prebuild: scripts/scoped-test
# and the rsi-rolling-land gate (crates/rsid/src/bin/rsi-rolling-land.rs) both
# read it, and scripts/tests/test_e2e_prebuild_single_definition.py enforces
# that. One "PACKAGE BINARY" pair per line; add a new sibling here only.
#
# `cargo test -p rsi --test e2e_tui` builds rsi itself. The daemon the harness
# spawns looks the rest up next to itself at runtime:
#   rsid            spawned by the harness (sibling of CARGO_BIN_EXE_rsi)
#   rsi-agent-mcp   trusted sibling every agent/provider session launch needs
#   rsi-rpc         trusted sibling for boundary-mail hooks
#   rsi-turn-shim   sibling that wraps detached Claude turns
rsid rsid
rsi-common rsi-agent-mcp
rsi-common rsi-rpc
rsi-turn-shim rsi-turn-shim
